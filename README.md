# 世界分析法

> 当遇到一切问题时都可以使用的分析法。

复杂问题、理论、架构、分类模型、重大决策、冻结前验证——无论面对的是什么，世界分析法都提供一套可执行的分析协议：**发现本质、攻击假设、校核证据，形成可以继续推进或可以冻结的结论。**

它不是七个 Prompt 的合集，也不是固定七步的 Workflow，而是一套**方法论路由协议**：针对当前问题，选择最少必要的方法组合，而不是把七种方法全部跑一遍。

## 核心思想

```text
先找本质，再建模型
先攻击模型，再相信模型
先确认外部证据证明了什么，再引用案例
只有真实观测能够决定的问题，才进入实证
```

以及：

> **选择最少的方法，获得足够的判断。**

## 怎么用

```text
先明确要判断什么
↓
选择最少必要方法
↓
按方法原生协议执行
↓
仅在结果触发下一方法时继续
↓
形成统一 Verdict
```

每个方法产出自己的原生 Verdict，最终综合为统一的结论 Envelope：结论、使用的方法、关键发现、原生 Verdict、未解决问题、Overall Status（Proceed / Conditional / Revise / Evidence Needed / Empirical Test Pending）、Freeze Readiness（Ready / Ready with Scope / Not Ready）。

## 七种方法

| # | 方法 | 核心问题 |
|---|---|---|
| 01 | 第一性约简 | 去掉现成答案后，最少什么必须成立？ |
| 02 | 对抗性约简 | 当前模型里什么可以删、并、解耦？ |
| 03 | 双向钢人 | 当前主张与最强竞争解释，谁更站得住？ |
| 04 | 正交性分析 | 当前分类是否把不同语义维度混在一起？ |
| 05 | 不变量与极端反例 | 什么必须始终成立，什么最容易击穿它？ |
| 06 | 外部证据校核 | 外部世界真正证明了当前 Claim 的哪一部分？ |
| 07 | 最小实证 | 最低成本做什么，才能获得足以改变决策的真实证据？ |

每种方法的完整定义、适用边界、核心动作、停止条件与原生 Verdict 见 [`references/`](references/) 下的对应文件。

## 适合什么场景

- **新领域 / 新概念**：这个东西本质是什么？
- **已有模型过度设计**：什么可以删、并、解耦？
- **重大方案取舍**：当前主张和最强的替代方案谁更站得住？
- **分类 / 状态 / 等级模型**：是否把不同维度混在一起了？
- **冻结前验证**：这个结论真的扛得住反例、证据和真实世界检验吗？

## 分析纪律

- **先结论，后关键理由**，不输出思维流水账。
- **不制造确定性**：允许 Conditional、Insufficient Evidence、Not Ready，不强迫明确胜负。
- **不虚构权重与阈值**：未经用户、业务规则或真实证据支持，不自行编造风险分数、可信度百分比。
- **术语不是事实，案例不是权威**：现有名词和成熟实践只是候选解释与外部证据。
- **最小 ≠ 极简**：所有约简必须同时满足 Minimum + Sufficient。
- **分析能力与工具能力分离**：环境无法搜索或实测时，明确说明未执行，并输出可执行的 Evidence Need / Experiment Design，不把设计伪装成结果。
